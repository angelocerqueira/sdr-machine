# sdr-machine — Regras Locais

Regras abaixo sao ESPECIFICAS deste repo e complementam o global.

## Stack

FastAPI + SQLAlchemy + PostgreSQL 16 + Alembic (backend).
Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS 4 (frontend).
Deploy: Railway (backend) + Vercel (frontend).
PM: **npm** (frontend). Backend: pip/venv.
Linter: ESLint (frontend), pytest (backend tests).

## Quality Gate

```bash
# Backend
cd backend && pytest

# Frontend
cd frontend && npm run lint && npm run build
```

## Dev Setup

```bash
# Backend + PostgreSQL
docker compose up --build    # localhost:8000

# Frontend
cd frontend && npm install && npm run dev   # localhost:3000
```

## Conventions

- Path alias: `@/*` -> `src/*` (frontend).
- All UI text in **PT-BR**. Variable names (`nicho`, `cidade`) in PT-BR.
- Pipeline: 4 stages (Scrape → Enrich → Generate → Outreach), each as FastAPI background task.
- Lead status flow: `scraped → enriched → lp_generated → outreach_ready → outreach_sent → responded → in_call → closed → delivered`.
- Enrichment: orchestrator pattern with 6 pluggable providers.
- LPs generated by Claude API (claude-sonnet-4-20250514).
- Frontend routes: `/` (marketing LP), `/app/*` (authenticated product), `/lp/[id]` (public LP preview).
- Middleware: `/app/*` protected, `/` and `/lp/*` public.
- Real-time: SSE via EventSource for job progress.
- Components: flat `.tsx` in `components/`, marketing in `components/marketing/`, remotion in `components/remotion/`.
- Animations: Remotion (hero), Framer Motion (scroll effects).
- No UI library — all custom components with Tailwind.
- Mobile-first (min-width breakpoints).
